### P1 — 视觉与一致性（建议做）

1. **深色主题靠 65 条 `[data-theme="dark"]` 逐条覆盖**，每加一个组件就要补一条，易漏（充值弹窗深色下就靠补丁）。建议：把组件级颜色全部收敛到 token（新增 `--surface-2`、`--table-head` 等语义变量），深色只覆盖 `:root` 一层，删除逐条覆盖。
2. **emoji 当图标**（📋⚡💰🚨…约 30 处）：不同系统渲染差异大、深色下发灰。建议：核心导航/状态条换行内 SVG（一套 1.5px 线性图标），emoji 仅保留在数据内容里。
3. **表格密度与层级**：充值/抄表/报表多张表样式各有微差（th 背景、行高不一）。统一一套 table 样式 + 斑马纹/悬停规则。
4. **按钮体系**：已有 btn/btn-secondary/btn-ghost/btn-sm，但仍有大量内联 padding 的"第四种按钮"（header-backup-btn + 内联 style）。收敛为 4 个标准类。
5. **状态色使用不一致**：成功绿有时 `--success` 有时直接 `color:var(--success)` 加内联；危险红同理。统一语义 badge 组件（`.badge--success/.badge--warn/.badge--danger`）。

### P2 — 交互体验（可选做）

1. **弹窗层级管理**：Esc 关闭逻辑手写了一个层级数组（modal_bindings.js），新增弹窗要记得手动登记。统一 Modal 管理器（已有 modals.js 基础）。
2. **表格空状态**：部分列表空时只有一行灰字，可加图标 + 引导按钮（"去抄表"/"去充值"）。
3. **数字表格右对齐 + 等宽数字**：度数/金额列用 `font-variant-numeric: tabular-nums`（Inter 支持），扫读更轻松。
4. **加载态**：报表/图表加载时无骨架或 spinner，弱网下白屏感明显。
5. **移动端**：断点已有但弹窗内长表单（充值/抄表）在 480px 下滚动体验一般，可做底部 sheet 化（CSS 已有部分基础）。

### P3 — 可访问性（低优先）

1. 图标按钮（主题切换、关闭 ✕）缺 `aria-label`
2. 表格无 `<caption>`/`scope`；图表 canvas 无文字替代
3. 焦点样式较弱，键盘导航不易感知
